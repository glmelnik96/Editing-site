# Список хода загрузки и заданий — дизайн

**Дата:** 2026-09-08
**Репозиторий:** Editing site
**Основание:** ход работы привязан к экрану: ушли с «Записей», «Субтитров» или «Рендера» — полосы нет; анализ на карточке — пилюля, не ход

---

## 1. Зачем

Человек загружает файл, ждёт анализ и прокси, заказывает расшифровку и сборку. Каждое дело уже считается на сервере (или в браузере, пока идут байты), но увидеть процент можно только там, где его начали. Нужен один список живых дел, который едет по сайту вместе с шапкой.

**Чего не делаем:** кнопку сброса расшифровки Whisper (есть «Собрать заново» — она заново режет карточки из той же расшифровки); поток SSE; пометку «ошибку прочитали» в базе; переход по клику на строку; модальное окно поверх монтажа; полосу на плеере шкалы; отмену анализа.

---

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Сброс Whisper и карточек | Не добавляем. «Собрать заново» остаётся как есть |
| Где список | Оболочка сайта, под шапкой, над экраном |
| На каких экранах | Все экраны вошедшего человека. На двери входа нет |
| Несколько дел сразу | Каждое — своя строка |
| Откуда данные | `GET /api/v1/jobs` плюс загрузки, которые считает браузер |
| Успех | Надпись «готово» около двух секунд, строка пропадает |
| Отмена человеком | Надпись «отменено» около двух секунд, строка пропадает |
| Сбой | Текст ошибки и «Закрыть». Пока вкладка открыта — строка живёт, даже если сервер уже не отдаёт задание. После обновления страницы сбой снова виден только в окне 30 с |
| Отмена из строки | Загрузка, расшифровка, сборка. Анализа и прокси — нет |
| Полосы на старых местах | Убираем. Кнопки и пилюли статусов остаются |
| Точка на вкладке редактора | Как сейчас: готовая расшифровка → «Субтитры», готовый ролик → «Рендер» |

---

## 3. Как это выглядит

Пустой список места не занимает.

Строка: действие, имя в кавычках, процент, полоса. Справа — «Отменить», если отмена разрешена. У анализа и прокси кнопки нет: без них запись в проект не встанет; передумали — удаляете запись.

Подписи действий:

- загрузка в браузере — `Загрузка «имя файла»`
- `analyze` — `Анализ «имя записи»`
- `proxy` — `Прокси «имя записи»`
- `transcribe` — `Расшифровка «имя записи»`
- `render` с `draft` — `Сборка черновика «имя проекта»`
- `render` с `final` — `Сборка финала «имя проекта»`

Имя записи — `original_name`. Имя проекта — `projects.name`. Нет объекта (удалили, пока задание доигрывало) — «запись удалена» / «проект удалён», строка не прячется, пока задание живо или пока сбой не закрыли.

Во вкладках «Субтитры» и «Рендер» полосы процентов нет. Остаются кнопки и короткая фраза вроде «Расшифровываю — ход вверху» / «Собираю — ход вверху». «Отменить сборку» на панели рендера остаётся: человек уже на этом экране и не обязан искать строку в шапке. На карточке записи пилюля статуса остаётся, повторный процент (`анализ, 40 %`) рядом с ней уходит — он живёт в списке хода.

Под зоной сброса на «Записях» отдельных полосок загрузки больше нет.

## 4. Сервер

Новая ручка `GET /api/v1/jobs`: вошедший человек, только его строки. Чужой идентификатор по-прежнему не светим: список просто не содержит чужого.

В ответ входят:

- все свои задания в `queued` и `running`;
- свои `done`, `canceled`, `failed` с `finished_at` не старше 30 секунд.

Не больше 50 строк, свежие первыми. Отдельной постраничности нет.

Поля строки списка — те же, что у `GET /api/v1/jobs/{id}` (`id`, `type`, `status`, `progress`, `error`, `created_at`, `finished_at`), плюс:

- `label` — человеческое имя, как в §3, без кавычек (кавычки рисует интерфейс);
- `cancelable` — истина только для `transcribe` и `render` в `queued` или `running`;
- `quality` — `draft` / `final` у сборки, иначе нет.

`GET /api/v1/jobs/{id}` не меняем: старые клиенты и смоук продолжают ходить за одним заданием.

Отмена — существующий `POST /api/v1/jobs/{id}/cancel`. Анализ по-прежнему `422 cannot_cancel`; в списке у него `cancelable: false`, кнопки нет.

Индекс по `user_id` и статусу (и `finished_at`), чтобы список не сканировал всю таблицу.

Авторизации нет — `401`, как у соседних ручек.

## 5. Клиент

Список монтируется один раз в оболочке, не внутри экрана записей и не внутри редактора. `hashchange` его не останавливает. Выход из аккаунта — опрос гаснет, строки очищаются.

Опрос `GET /api/v1/jobs` раз в те же ~2–3 секунды, что и карточки записей. Срыв запроса не обнуляет список: остаётся последний удачный снимок и тихая пометка, что ход мог устареть.

Загрузки не ходят в эту ручку. Экран записей сообщает оболочке: имя файла, уже переданные байты, всего байт, обрыв. Пока `XMLHttpRequest` жив — строка `Загрузка`. Обрыв — строка исчезает. Успех — «готово» ~2 с, затем строка анализа появится с сервера, когда воркер возьмёт задание.

Склейка: ключ строки задания — `job.id`; ключ загрузки — клиентский, пока запрос не закончился. Одно дело не рисуем дважды.

Клиентские надписи «готово» / «отменено» живут у себя: сервер ещё ~30 с может отдавать `done` / `canceled`, интерфейс прячет строку через ~2 с.

Сбой `failed`: как только строка попала в список этой вкладки, она остаётся до «Закрыть», даже когда сервер её уже не отдаёт. Множество закрытых id — только память вкладки. Обновили страницу — снова показываем сбой, если он ещё в окне 30 с; если окно прошло, строки нет, текст ошибки остаётся на карточке записи или во вкладке, где её умеют показать. Не смотрели 30 с после сбоя — список его не видел и не покажет.

Неудачная отмена пишет текст в ту же строку, строку не удаляет.

## 6. Тестирование

- **Список заданий:** только свои; `queued`/`running` всегда; `done` старше 30 с не входит; чужой пользователь — пусто, не 403; `label` с имени записи и проекта; нет записи — запасная подпись; `cancelable` истинен у живых `transcribe`/`render` и ложен у `analyze`/`proxy` и у уже законченных.
- **Отмена:** из списка нельзя отменить анализ (кнопки нет; прямой POST как сейчас `422`).
- **Экран:** на «Записях» нет полос под зоной сброса; во вкладках «Субтитры» и «Рендер» нет `.progress` у задания; пилюля статуса на карточке без повторного процента.
- **Склейка:** две загрузки и одно `analyze` — три строки; успех загрузки не оставляет вечную полосу.
- **Живая проверка:** загрузить файл на «Записях» — полоса в шапке; уйти на главную — полоса на месте; анализ и прокси сменяют друг друга; в редакторе расшифровка и черновик видны без открытой вкладки; отмена сборки из строки; сбой остаётся до «Закрыть».
- **Не ломается старое:** `GET /jobs/{id}`, отмена, смоук агента, прежние тесты воркера.

## 7. Вне рамок
