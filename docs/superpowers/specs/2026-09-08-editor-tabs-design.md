# Вкладки редактора: одна работа слева — дизайн

**Дата:** 2026-09-08
**Репозиторий:** Editing site
**Основание:** на «Субтитрах» и «Рендере» всё ещё видны исходники и музыка; три работы свалены в одну колонку

---

## 1. Зачем

Слева три вкладки, но исходники и музыка не прячутся. Человек правит реплики или собирает файл и одновременно видит плеер исходника и микс. Путь «нарезать → реплики → файл» не читается.

Справа (плеер ролика, полоса, шкала) — это сам ролик, его не трогаем. Слева должна быть только выбранная работа.

**Чего не делаем:** четвёртую вкладку «Музыка»; дорожку музыки на шкале; отдельные hash на каждую вкладку; мастер-шаги; прятать или урезать полосу над шкалой; чистить реплики при удалении последнего клипа; менять главную, записи, конвертер, `#/new`.

---

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Левая колонка | Видна одна вкладка. Исходники и музыка только на «Исходниках» |
| Музыка | Остаётся в «Исходниках» |
| Полоса над шкалой | Не меняется ни на одной вкладке |
| Пустая шкала | «Субтитры» и «Рендер» серые, клик не открывает |
| Первый клип | Обе вкладки включаются, сами не переключаемся |
| Удалили последний клип, стояли на субтитрах | Возврат на «Исходники». Реплики в документе остаются |
| «Рендер» без клипов | Живая, если есть готовый ролик (скачать). Нет клипов и нет файлов — серая |
| Задания | Расшифровка и сборка не зависят от открытой вкладки. Ход в шапке |
| Точка «новости» | На серой вкладке не делает её кликабельной |

Отложенные подходы: свёртка исходников в одну строку; музыка своей вкладкой; дорожка на шкале.

---

## 3. Карта экрана

Редактор — одно окно. Справа всегда: плеер ролика, полоса (▶, резка, громкость клипа, переход, кадр, fps, галочка «Субтитры»), шкала.

Слева три кнопки. Содержимое одной:

| Вкладка | Содержимое |
|---|---|
| Исходники | Файл, плеер исходника, «в шкалу», текст, музыка |
| Субтитры | Реплики с шкалы (не со склада): расшифровать, собрать, править |
| Рендер | Сводка, черновик / финал, список скачивания |

Панель рендера по-прежнему монтируется при первом успешном открытии.

`#ed-source { display: flex }` не должен перебивать `hidden`: для спрятанного исходника — `#ed-source[hidden] { display: none }`.

---

## 4. Когда вкладка живая

«Исходники» всегда живые.

«Субтитры» живые только если на шкале есть хотя бы один клип.

«Рендер» живая, если есть клип **или** в проекте есть хотя бы один готовый ролик (`GET /api/v1/projects/{id}/renders` не пуст). Список роликов нужен при загрузке редактора, не только после открытия вкладки. После удаления последнего готового файла при пустой шкале вкладка снова серая.

Серая вкладка: `disabled`, клик игнорируется, `showTab` на неё не переключает. Если текущая вкладка стала неживой (сняли последний клип на субтитрах, или сняли последний клип и удалили все ролики на рендере) — показать «Исходники».

Автоперехода на «Субтитры» / «Рендер» при появлении клипа нет.

---

## 5. Что не меняется внутри панелей

Исходники, музыка, субтитры (реплики только со шкалы), рендер — состав и копирайт как сейчас. Расшифровка: «Можно уйти на другую вкладку, работа не прервётся». Сборка: ход в шапке, «Отменить сборку» на панели рендера.

---

## 6. Проверки

- На «Субтитрах» нет блока исходника и музыки; на «Рендере» — тоже.
- Пустой проект: две правые вкладки `disabled`; клик оставляет «Исходники».
- После первого клипа вкладки живые.
- На субтитрах удалили последний клип → «Исходники», «Субтитры» серые.
- Есть готовый ролик, клипов нет → «Рендер» живой, «Субтитры» серые.
- `#ed-source[hidden]` даёт `display: none`.
- Полоса над шкалой на всех вкладках с теми же кнопками.

Живая проверка: новый проект — серые вкладки; кусок на шкалу — открываются; субтитры без исходников слева; рендер без исходников; уйти во время расшифровки — ход в шапке.
