# Путь: записи, конвертер, новый проект — дизайн

**Дата:** 2026-09-08
**Репозиторий:** Editing site
**Основание:** конвертер живёт внутри записей, новый проект снова просит выбрать файл, кнопка входа на hover нечитаема

---

## 1. Зачем

Три разные работы сейчас свалены в одни окна. Запись — и склад, и конвертер, и вход в монтаж. Новый проект дублирует выбор файла, который уже есть в исходниках редактора. Человек не видит, какой шаг обязательный.

Конвертер — боковая ветка: извлечь звук или другой файл, не собирая нарезку. Монтаж начинается с имени ролика, а не с повторного выбора записи. Дверь гостя должна читаться при наведении.

**Чего не делаем:** ссылки «Записи / Проекты / Конвертер» в шапке (карта остаётся на главной); gif; свободный ffmpeg; пакетную конвертацию нескольких файлов; загрузку на экране конвертера; подстановку «Без названия» или даты вместо имени.

---

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Карта экранов | Записи `#/files`, конвертер `#/convert`, новый проект `#/new` |
| Шапка | Как сейчас: квота, настройки, кабинет доступа, выход. Новых пунктов нет |
| Главная 2.1 | Та же карточка «Конвертировать», адрес `#/convert` |
| Записи | Склад: загрузка, статус, удалить. Без конвертера и без «В проект» |
| Конвертер | Инструмент: файл, формат, «Конвертировать», список готовых |
| Форматы | mp3, m4a, aac, wav, flac, ogg; у видео ещё mp4 и webm. Gif — 422 |
| История конверсий | Все готовые файлы этого человека, не только выбранного исходника |
| Новый проект | Только обязательное имя и «Создать». Пустая шкала |
| Имя проекта | «Создать» неактивна, пока после `trim` поле пустое. Сервер уже требует 1–200 знаков |
| Дверь | Подпись всегда «Войти». Текст тёмный на мяте и в покое, и на hover |
| Пустая шкала | Строка «Добавьте кусок из исходников», пока нет клипа |

Отложенные подходы: конвертер как режим `#/files?convert=1`; точечные правки на текущих экранах без новых адресов.

## 3. Дверь гостя

Кнопка остаётся ссылкой `/api/v1/auth/login`. Текст **«Войти»** в покое и при наведении. Яндекс на кнопке не пишем: вход и так идёт через него.

Причина нечитаемости: `.btn-key` даёт тёмный текст на зелёном, общее правило `a:hover` красит ссылку в `--brand-hover` — тот же зелёный, что фон кнопки на hover. Лечится не сменой тега, а цветом: `.btn-key:hover:not(:disabled)` явно ставит `color: var(--brand-ink)`. Это правило для всех ключевых кнопок-ссылок, не только двери.

Hover фона — как сейчас, `--brand-hover`. Заголовок, лид и анимация двери не меняются.

---

## 4. Главная и шапка

Шапка вошедшего не расширяется. Три работы по-прежнему читаются с главной.

Карточка шага 2.1 меняет только `href`: было `#/files`, становится `#/convert`. Номер шага, заголовок «Конвертировать» и лид про извлечение звука без нарезки остаются.

Шаг 1 по-прежнему `#/files`, шаг 2 — `#/new`. Недавние проекты и «Все проекты» без изменений.

## 5. Записи

Экран `#/files` — библиотека исходников.

На карточке: кадр, имя, длительность, размер, пилюля статуса, «Удалить». Нет чипов формата, нет списка конверсий, нет «В проект».

Опрос статуса записей (анализ, прокси) остаётся. Опрос заданий конвертации и подгрузка конверсий с этого экрана уходят вместе с панелью.

`rememberPick` / `takePick` больше никому не нужны: выбор файла для монтажа только в исходниках редактора. Вспомогательные функции убираем, если после правки на них нет ссылок.

## 6. Конвертер

### 6.1 Экран

Новый маршрут `#/convert`. Неизвестный hash по-прежнему главная; `/convert` — исключение, как `/files`.

Состав сверху вниз:

1. Заголовок «Конвертер».
2. Выбор файла: готовые (`ready` / `proxy_ready`) видео и звук этого человека. Подпись — имя и длительность. Нет готовых — текст «Сначала загрузите запись» и ссылка на `#/files`. Чипов и кнопки нет.
3. Ссылка «Нет файла? Загрузить в записях» есть и когда список не пуст.
4. Чипы формата. Выбран один. Для видео: mp3, m4a, aac, wav, flac, ogg, mp4, webm. Для звука — те же без mp4 и webm.
5. Кнопка «Конвертировать» запускает задание выбранного формата. Пока по этому файлу уже идёт `queued`/`running`, чипы и кнопка неактивны. Ход: короткая фраза, полоса, «Отменить» — как на старой панели карточки. Список хода в шапке для `convert` уже есть, его не трогаем.
6. Список «Готовые файлы»: все живые конверсии человека, свежие сверху. Строка: имя исходника, формат, длительность, размер, «до …», «Скачать», «Удалить».

Пустой список готовых — не ошибка, просто нет строк.

### 6.2 Сервер

`POST /api/v1/assets/{id}/convert` и удаление одной конверсии не меняют контракт, кроме белого списка форматов.

`FORMATS`: `mp3`, `m4a`, `aac`, `wav`, `flac`, `ogg`, `mp4`, `webm`. Клиент по-прежнему шлёт строку `format`, не командную строку. Аргументы ffmpeg только из таблицы в `server/media/convert.py`.

Аудиовыходы (`mp3`, `m4a`, `aac`, `wav`, `flac`, `ogg`) с файла без звука — `422 no_audio`. `mp4` и `webm` только из видео — `422 not_video`. `gif` и прочее вне списка — `422 invalid_format`.

Кодеки, которых может не быть в сборке на ВМ, проверяем до постановки в очередь, ответ `503 encoder_unavailable` без stderr ffmpeg:

- mp3 — как сейчас, `libmp3lame`;
- webm — VP9 (`libvpx-vp9`) и Opus (`libopus`). Нет любого из двух — 503, в тексте предложить mp4.

aac / flac / ogg считаем обычными, как wav и m4a: отдельного зонда до очереди нет. Сбой воркера остаётся заданием `failed` с человеческим текстом.

Оценка места: aac и ogg как m4a/mp3; flac как wav (с запасом); webm как mp4. `CONVERT_EXTS` в storage расширяется теми же расширениями, иначе janitor не узнает файлы.

Новая ручка `GET /api/v1/conversions`: вошедший человек, только свои строки, свежие первыми. Поля как у текущей карточки конверсии плюс `original_name` исходника. Чужой идентификатор в списке не появляется. Постраничности нет: на исходник не больше десяти готовых (`MAX_READY`), у одного человека это десятки строк, не лента.

`GET /api/v1/assets/{id}/conversions` можно оставить для совместимости и тестов; экран конвертера ходит в общий список.

Вытеснение старших сверх пула — по-прежнему на исходник, не глобально.

## 7. Новый проект и пустая шкала

`#/new`: заголовок «Новый проект», поле имени, «Создать». Плиток записей нет. Нет состояния «сначала загрузите запись» на этом экране: пустой склад не мешает создать проект.

Плейсхолдер поля — про название ролика, не «можно не заполнять». Кнопка `disabled`, пока `value.trim()` пустой. Пробелы сами по себе не имя. Клиент не подставляет имя файла и не шлёт пустую строку.

По нажатию: `POST /api/v1/projects` с `{ name }` без `doc`. Сервер уже собирает пустой документ. Второго сохранения с клипом нет. Успех — переход в `#/p/{id}`. Отказ (`too_many_projects`, сеть) — текст ошибки, кнопка снова активна.

В редакторе пустая шкала показывает одну приглушённую строку: **«Добавьте кусок из исходников»**. Появляется, когда клипов ноль; пропадает с первым клипом. Не блокирует шкалу и не подменяет исходники.

Если готовых видео нет, в панели исходников заметная ссылка на `#/files` («Загрузите запись»). Выпадающий список как сейчас: «— выберите файл —».

## 8. Ошибки

| Случай | Поведение |
|---|---|
| Нет готовых файлов в конвертере | Текст и ссылка, не красная ошибка |
| 422 формат / нет звука / не видео / файл не готов | Сообщение у формы конвертера |
| 409 already_queued | Не стартуем вторую; чипы молчат, пока живое задание |
| 503 нет кодека mp3 или webm | Текст выбрать другой формат |
| Сбой задания | Как сейчас: ошибка в списке хода шапки и на экране конвертера |
| Пустое имя проекта | Кнопка не шлёт запрос. Если обойти — сервер 422, имя 1–200 |
| Hover кнопки входа | Текст остаётся `--brand-ink` |

Сырой stderr ffmpeg на клиент не выходит — это уже правило конвертера.

## 9. Проверки

- Маршрут `#/convert` открывает экран конвертера, мусор в hash по-прежнему главная.
- Главная 2.1 ведёт на `#/convert`, не на `#/files`.
- На `#/files` нет чипов формата, списка конверсий и «В проект».
- Конвертер: нет готовых файлов — ссылка в записи, без чипов. Есть видео — видны mp4 и webm. Есть только звук — их нет.
- `POST` с `aac` / `flac` / `ogg` / `webm` принимается на подходящем ассете; `gif` и `webm` с аудиоассета — 422.
- `GET /api/v1/conversions` отдаёт только свои строки с `original_name`.
- Нет кодека webm — 503 до очереди, как mp3.
- `#/new` без выбранного файла создаёт проект с нулём клипов. Кнопка с пустым именем неактивна.
- В исходниках после создания список файлов на месте, на шкале — подсказка, пока клипов нет.
- Дверь: в разметке «Войти»; у `.btn-key:hover` цвет `--brand-ink`.

Живая проверка на проде после выкладки: hover входа, три адреса с главной, создать проект без файла, конвертировать в новый формат и скачать не с карточки записи.
