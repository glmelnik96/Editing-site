# Одна вкладка субтитров и сохранения проекта — дизайн

**Дата:** 2026-09-07
**Репозиторий:** Editing site
**Основание:** после M6 человек не находит, как субтитры попадают в ролик; точки сохранения спорят за левую колонку

---

## 1. Зачем

Сейчас расшифровка и субтитры — две вкладки с похожими кнопками, «наложить» — только подпись, а не действие, и готовые реплики всегда едут в сборку. Точки сохранения сидят четвёртой вкладкой и второй кнопкой над шкалой. Человек не собирает путь «расшифровать → реплики → в ролик / без них» и не понимает, куда делись снимки проекта.

**Чего не делаем:** не даём править сырой текст Whisper; не оставляем монтаж по словам («Взять кусок»); не рисуем субтитры поверх плеера монтажа; не вводим отдельную дорожку с панели; не переделываем пул снимков и автосохранение монтажа.

---

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Вкладки редактора | Исходник · Субтитры · Рендер |
| Правка после расшифровки | Только карточки реплик, не сплошной текст |
| Монтаж по словам | Убираем вместе со вкладкой «Транскрибация» |
| Как выключить субтитры в ролике | Галочка над шкалой, реплики не удаляются |
| Что значит галочка | Признак `enabled` у блока субтитров |
| Нет признака у старого проекта | Считать включённым: уже собранные ролики не теряют субтитры |
| Вжечь или дорожкой | С панели только вжечь; `mode: "soft"` остаётся для агента |
| Точки сохранения | Кнопка «Сохранения проекта» справа в шапке, список выпадает вниз |
| Кнопка «Сохранить точку» над шкалой | Убрать |
| Плеер монтажа | По-прежнему без наложения: реплики видны в карточках и в собранном файле |

---

## 3. Путь во вкладке «Субтитры»

Одна панель, выбранный в «Исходнике» файл.

1. Расшифровки нет — кнопка «Транскрибировать». Пояснение: займёт несколько минут, с вкладки можно уйти.
2. Задание идёт — полоса хода. Повторный заказ по-прежнему `409 already_queued`.
3. Расшифровка готова — кнопка «Собрать субтитры». Она кладёт реплики в документ (`source: "cues"`, `mode: "burn"`) и ставит `enabled: true`.
4. Карточки: начало, конец, две строки. Правка — обычная правка документа (откат, автосохранение, снимки). «Собрать заново» спрашивает и затирает правки карточек.

Текста расшифровки на этой панели нет: он нужен был, чтобы монтировать словами, а этот путь уходит. Расшифровка остаётся файлом записи и сырьём для «Собрать субтитры».

Подпись «Субтитры войдут в ролик при следующей сборке» уходит вместе с выбором «вжечь / дорожкой»: про ролик говорит галочка над шкалой. Выбор режима с панели убираем; кнопка «Собрать» всегда шлёт `mode: burn`.

Редактор больше не монтирует панель транскрибации. Модуль чистых функций вокруг слов (`flattenWords` и соседи) можно оставить, если на него ещё смотрят тесты; вход «Взять кусок» с экрана исчезает.

---

## 4. Галочка над шкалой

В ряду монтажа, рядом с «играть» и «разрезать», подпись **Субтитры**.

- Реплик в документе нет — галочка неактивна: включать нечего.
- После «Собрать субтитры» включается сама (`enabled: true`).
- Сняли — `enabled: false`, карточки на месте.
- Поставили снова — те же реплики, тот же вычитанный текст.

Галочка не вызывает «Собрать субтитры» и не ходит в расшифровку. Это обычная правка документа через савер, как текст карточки: очередь, откат, конфликт версий. Карточки из-за галочки не пересобираются.

Галочка живая, когда в документе есть реплики (`source: "cues"` и непустой `cues`). Источники агента `file` и `transcript` с панели не ставятся; их `enabled` агент пишет в документ сам.

---

## 5. Документ и сборка

Блок `doc.subtitles` получает логический признак `enabled`.

Нормализация в `validate_doc`: ключа нет → `true`; значение не булево → ошибка поля, не молчаливое приведение. Признак входит в возвращаемый объект — неизвестные поля по-прежнему отбрасываются, этот ключ известный.

Правка карточек не сбрасывает `enabled`: клиент при `PUT` отправляет его вместе с репликами, сервер его сохраняет. `POST /projects/{id}/subtitles/generate` заменяет блок целиком и ставит `enabled: true`: человек только что собрал реплики, чтобы они были в ролике.

Сборка ролика смотрит на признак, а не только на наличие блока. Сейчас `build_render_command` при любом блоке субтитров кладёт фильтр; пустой путь при `source: "cues"` — ошибка, а не «без субтитров». Поэтому выключенный блок нужно считать отсутствующим **в сборщике команды** (воркер и прямые вызовы `build_render_command`). Иначе снять галочку и собрать черновик нельзя.

`build_project_subtitles` по-прежнему пишет кэш SRT, пока в документе есть реплики или расшифровка: `GET /projects/{id}/subtitles` отдаёт файл даже при снятой галочке. Сборка ролика на этот GET не смотрит.

Источники `file` и `transcript` подчиняются тому же признаку: выключены — в ffmpeg нет ни вжигания, ни мягкой дорожки.

С панели режим «отдельной дорожкой» уходит. Поле `mode` в документе остаётся: человек всегда получает `burn`, агент может прислать `soft`.

---

## 6. Сохранения проекта

В шапке проекта справа кнопка **Сохранения проекта**. По клику выпадает список: поле подписи, «Сохранить», до пяти снимков, у каждого «Вернуться». Повторный клик и клик снаружи закрывают список. Пул, вытеснение и `VIDEO_VERSIONS_KEPT` не меняются. Перед снимком и перед возвратом по-прежнему сбрасывается очередь правок.

Вкладки «Точки» нет. Кнопки «Сохранить точку» над шкалой нет. Автосохранение монтажа по-прежнему не создаёт снимок.

---

## 7. Точка новостей

Готовая расшифровка помечает вкладку **Субтитры**, если она закрыта. Готовый ролик — вкладку **Рендер**, как сейчас. Вкладки транскрибации нет, точки новостей на ней тоже нет.

---

## 8. Тестирование

- **Документ:** нет `enabled` → после проверки `true`; не булево → отказ; явный `false` сохраняется; generate ставит `true`; правка реплик `enabled` не затирает.
- **Сборка:** `enabled: false` при живых репликах — в команде ffmpeg нет фильтра субтитров и нет ошибки «реплики не собраны»; нет ключа — фильтр как сейчас. То же для `file` и `transcript`.
- **Экран:** три вкладки; галочка серая без реплик; после сборки включена; снимки открываются из шапки; выбора burn/soft на панели нет.
- **Живая проверка:** расшифровать → собрать → поправить карточку → черновик с субтитрами в кадре; снять галочку → черновик без них; включить снова → правка на месте. Снимок из шапки и возврат к нему. Автосохранение монтажа снимок не создаёт.
- **Не ломается старое:** прежние прогоны API и воркера зелёные; проект без поля `enabled` собирается с субтитрами.

---

## 9. Вне рамок

Правка текста расшифровки, караоке в кадре, стили кроме `default`, мобильная вёрстка редактора, отдельная дорожка с панели, монтаж по словам, наложение субтитров на плеер монтажа.
