# SB Sans — шрифты сервиса

Общие с соседями по ВМ: Presentation Remote и VideoBoard. Получены из OTF-библиотеки
владельца через fontTools, файлы закоммичены ради воспроизводимой сборки — Vite кладёт
их в `dist/fonts/` как есть.

| Файл | Начертание | Где используется |
|---|---|---|
| `sb-sans-display-300.woff2` | Display Light | крупное: приветствия, заголовки экранов |
| `sb-sans-text-300.woff2` | Text Light | пояснения под заголовками |
| `sb-sans-text-400.woff2` | Text Regular | весь остальной текст |

Прочих начертаний нет намеренно: каждое — это лишние 30 КБ на первой загрузке,
а трёх хватает на всю систему.
